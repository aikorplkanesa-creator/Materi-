BELAJAR DENGAN MEMBUAT

Proyek bertahap

Gunakan proyek untuk menggabungkan beberapa konsep sekaligus.

01
PEMULA

Halaman profil pribadi

Gunakan HTML untuk judul, paragraf, gambar, tautan, dan daftar.

HTML Konten semantik
Langkah pengerjaan
  1. Buat file index.html.
  2. Tambahkan nama, deskripsi, hobi, dan cita-cita.
  3. Gunakan heading dan list dengan benar.
  4. Uji semua tautan di browser.
02
MENENGAH

Kartu portofolio responsif

Gabungkan HTML dan CSS untuk membuat kartu yang rapi di HP dan desktop.

HTML CSS Grid/Flexbox
Langkah pengerjaan
  1. Buat struktur profil dan daftar skill.
  2. Gunakan Flexbox atau Grid.
  3. Tambahkan media query untuk layar kecil.
  4. Uji dengan lebar layar berbeda.
03
MENENGAH

Daftar tugas interaktif

Tambah, tandai selesai, dan hapus tugas menggunakan JavaScript.

DOM Events
Langkah pengerjaan
  1. Buat input dan tombol tambah.
  2. Baca nilai input dengan JavaScript.
  3. Buat elemen tugas dan event klik.
  4. Tambahkan validasi input kosong.
04
LANJUTAN

Aplikasi catatan Python

Latih fungsi, list/dictionary, file, dan penanganan kesalahan.

Python File I/O
Langkah pengerjaan
  1. Buat menu tambah dan lihat catatan.
  2. Pisahkan logika ke beberapa fungsi.
  3. Simpan catatan ke berkas JSON.
  4. Tangani input yang tidak valid.
05
LANJUTAN

Dashboard data sederhana

Gunakan Python untuk membaca data, membersihkan nilai, dan membuat ringkasan.

Python Data
Langkah pengerjaan
  1. Siapkan data contoh berbentuk CSV.
  2. Baca data dan periksa nilai kosong.
  3. Hitung jumlah, rata-rata, atau kategori.
  4. Tampilkan hasil dengan tabel atau grafik.
06
PORTOFOLIO

Website portofolio lengkap

Bangun halaman tentang saya, proyek, skill, dan kontak dengan navigasi responsif.

HTML CSS JavaScript
Langkah pengerjaan
  1. Rencanakan struktur dan isi halaman.
  2. Gunakan komponen visual konsisten.
  3. Tambahkan navigasi dan interaksi.
  4. Periksa aksesibilitas dan responsivitas.
  5. Publikasikan setelah pengujian.
